C1.1

Atoms

Elements, symbols, compounds and mixtures

Learn
same colour = same elementdifferent colour = different elementline = chemical bond

Element

Contains only one type of atom. Each element has a chemical symbol, such as O, Na or Cl.

Compound

Contains atoms of two or more elements chemically bonded in fixed proportions. H₂O has two H atoms for every O atom.

Mixture

Contains substances that are not chemically combined. The proportions can vary and the substances can be separated physically.
