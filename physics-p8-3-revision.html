💡 The Big Idea

Wherever you are, at least two forces act on you — gravity pulling you down, and a surface pushing you up. The resultant force is the single force that has the same effect as all of them combined.

🔢
Resultant Force

One force replacing all others with identical effect

⚖️
Balanced

Resultant = 0 N → object stays still or moves at constant speed

🚀
Unbalanced

Resultant ≠ 0 N → speed or direction changes

📐
Free-body Diagram

Shows all forces on one object as arrows (vectors)

⚖️ Balanced Forces

Newton's First Law of Motion
If the forces on an object are balanced (resultant = 0 N), the object either stays at rest OR keeps moving at the same speed in the same direction.

✅ Object at rest

  • → It stays stationary
  • → Forces cancel perfectly
  • → e.g. book on a table

🔄 Object in motion

  • → Keeps moving at same speed
  • → Same direction maintained
  • → e.g. glider on air track
🛸
Air track glider example: The air track removes friction. With no unbalanced force, the glider floats along at constant speed — Newton's 1st Law in action.
📦
Crate on rough floor: Pushed at constant speed → push force = friction force. Resultant = 0 N, so it doesn't accelerate.

🚀 Unbalanced Forces

When resultant force ≠ 0, the object accelerates (speeds up, slows down, or changes direction).

Two forces in opposite directions
Resultant = difference between the two forces, acting in the direction of the larger force

📐 Free-body Force Diagrams

Definition
A free-body diagram shows ALL forces acting on ONE object only, with each force shown as a vector arrow pointing in the direction of the force.
✅
IS a free-body diagram: A single car with arrows for engine force, braking force, weight, and road support — all on that car alone.
❌
NOT a free-body diagram: A tug-of-war scene showing two teams — it shows forces on more than one object.
📏
Vectors matter: Arrow length represents force magnitude. Always draw arrows from the object, pointing in the direction of the force.

🧮 Calculating the Resultant Force

➡️➡️
SAME DIRECTION
F = A + B
Add the forces
Direction stays the same
⬅️➡️
OPPOSITE DIRECTIONS
F = A − B
Subtract the smaller
Direction = larger force
📌

Worked Example

Two forces act on an object in opposite directions: A = 5 N and B = 9 N.
Resultant = 9 − 5 = 4 N in the direction of B.

⚡ Common Exam Traps

⚠️

Study Tip — Don't Fall for This!

A common error: if the resultant force on an object is zero, it doesn't mean it must be stationary. It could be travelling at constant speed in a straight line. Zero resultant = no change in motion.

❌
Wrong: "The object is stationary because the forces are balanced."
✅
Correct: "The object is either stationary or moving at constant velocity because the resultant force is zero."
🖊️
Scale diagrams: In vector scale diagrams, use a ruler and protractor. State the scale clearly. Arrow length = force magnitude.

📖 Key Terms Glossary

Resultant Force
The single force that has the same effect as all forces acting on an object combined.
Balanced Forces
When the resultant force on an object is zero — it doesn't change its motion.
Unbalanced Forces
When the resultant force is not zero — the object accelerates (changes speed or direction).
Newton's First Law
An object stays at rest or at constant velocity unless acted on by an unbalanced force.
Free-body Diagram
A diagram showing all forces acting on ONE object as vector arrows.
Vector
A quantity with both magnitude and direction, shown as an arrow.

🏆 Key Points Summary

1️⃣
The resultant force is a single force that has the same effect as all the forces acting on an object.
2️⃣
If resultant = 0 N → object stays at rest or constant speed/direction.
3️⃣
If resultant > 0 N → speed or direction changes (acceleration).
4️⃣
Same direction → add the forces. Opposite directions → subtract, direction = larger force.
5️⃣
A free-body force diagram shows forces on ONE object as vector arrows.
