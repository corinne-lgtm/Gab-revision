Q2 Explain the difference between a WHILE loop and a DO…UNTIL loop. Include reference to when the condition is checked and whether the body is guaranteed to run. [4 marks]
Answer

Mark Scheme — Q2 [4 marks]

✓ A WHILE loop checks the condition before each iteration [1]
✓ If the condition is FALSE at the start, the WHILE loop body never executes (runs zero times) [1]
✓ A DO…UNTIL loop checks the condition after each iteration [1]
✓ A DO…UNTIL loop always executes its body at least once [1]

Answer

Mark Scheme — Q5 [3 marks]

✓ A local variable is declared inside a subroutine and only exists while that subroutine is executing [1]
✓ It cannot be accessed from outside the subroutine [1]
✓ Local variables are preferred because they prevent accidental changes from other parts of the program / makes programs easier to debug and maintain / reduces side effects [1]
