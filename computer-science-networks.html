AQA 3.5 · Networks

What is a network?

Connected devices and why we use them

What is a computer network?

A network is two or more devices connected so they can communicate or share resources, such as files, printers and an internet connection.

Example: school laptops use one shared printer and shared file storage.

Advantages vs disadvantages

BenefitsDrawbacks
Share hardware and files; collaborate; central managementSecurity threats can spread; setup/maintenance costs; outages affect users
GCSE technique: to explain a benefit, say what happens and why it matters. “One printer can serve many classrooms, reducing equipment cost” scores better than “sharing is good”.

PAN, LAN and WAN

Choose the network based on its size and ownership

PAN

Personal Area Network. A short-range connection between personal devices. For AQA, know Bluetooth: phone + headphones.

LAN

Local Area Network. Covers a limited area, such as a home, school or office. Usually owned/managed by one person or organisation.

WAN

Wide Area Network. Spans large geographical areas, connects networks, and typically has distributed/collective ownership. The Internet is the largest example.

Wired or wireless?

Copper, fibre and Wi-Fi: match the choice to the situation

Wired connection

Uses copper (Ethernet) or fibre-optic cables. Often more reliable, with lower interference and predictable performance, but devices are less mobile and cables can be expensive to install.

Copper: common short-distance office connections; generally cheaper. Fibre: light signals, high bandwidth, suitable for long distances; often more expensive to install.

Wireless connection

Uses radio signals, e.g. Wi-Fi. Lets phones and laptops move around and connect without cable runs. Signals can suffer interference, obstacles, congestion and range limits. Network access must be secured.

Exam trap: “wireless is always slower” is too absolute; performance depends on the equipment and conditions.

Protocols and what they do

The rules that allow devices to communicate

Protocol = agreed communication rules

A network protocol is a set of rules that devices follow to exchange data. Without common rules, equipment may not understand incoming messages.

Six AQA protocols

ProtocolPurpose — easy to remember
TCPReliable delivery: sequencing, checking and re-sending missing data
IPAddressing and routing packets towards their destination
HTTPTransferring web pages and other web resources
HTTPSSecure web communication, using encryption
SMTPSending email (client to server / between mail servers)
IMAPAccessing and synchronising email stored on a server

Web example

Your browser requests a page with HTTPS; IP helps packets find the destination; TCP supports reliable delivery.

Email example

SMTP sends your email; IMAP accesses/synchronises your inbox on different devices.

Keeping networks secure

Four protective methods — and why they work together

Authentication

Checks who a user is before giving access: passwords, passkeys or an additional sign-in factor. It does not automatically encrypt data.

Encryption

Scrambles readable data into ciphertext so someone intercepting it cannot easily understand it without the right key. Used by HTTPS.

Firewall

Monitors incoming/outgoing network traffic and allows or blocks traffic using security rules.

MAC address filtering

Allows or blocks devices using the hardware address of their network adapter. Useful as an extra layer, but MAC addresses can be spoofed, so it is not sufficient alone.

Layered defence — a school network

Student signs in→Encrypted traffic→Firewall rules→Device access controls

Why combine methods? Each protects against a different risk. A password cannot stop every malicious connection; encryption does not decide who is allowed to log in.

Exam technique: always link the security method to the specific threat in the scenario.

Four-layer TCP/IP model

Follow a message from an app to a network cable

Layer order — top to bottom

4 · Application

Web browsers and email programs use protocols like HTTP, HTTPS, SMTP, IMAP.

3 · Transport

Communication between hosts; agrees settings (including packet sizes). TCP works here.

2 · Internet

Addresses data and routes packets across networks. IP works here.

1 · Link

Where network hardware such as the NIC and operating-system device drivers work.

Memory trick: All Teachers Inspire Learning — Application, Transport, Internet, Link.

Follow a web request

Application: HTTPS request↓Transport: TCP↓Internet: IP↓Link: NIC

At the other computer, the data travels back up the layers to the receiving application. Each layer has a separate role.
