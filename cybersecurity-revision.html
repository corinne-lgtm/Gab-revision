Cyber security is concerned with the protection of computer systems, networks and data from digital attacks, damage and unauthorised access.

Common Threats

Malware Social Engineering Weak Passwords Default Passwords Removable Media Unpatched Software Misconfigured Access
Software purposely developed to damage, disrupt or take control of computer systems.
Techniques that manipulate people into giving away confidential and personal information.
Passwords using dictionary words are easy to crack using brute-force algorithms that try every word systematically.
Default passwords given at registration are often sent unencrypted by email — a major vulnerability if not changed.
USB drives and other removable media can be a vector for transmitting malware to a computer.
Software needs regular updates to fix security vulnerabilities. Unpatched software remains vulnerable to attack.
Users should only access the files and data they need — misconfigured rights give users access they shouldn't have.
⭐ Exam tip: When asked to "define cyber security", you need TWO points — mention protecting systems/networks AND mention threats/attacks/unauthorised access.

🦠 Malware Types

💻 Virus
Replicates and transfers between computers. Activated by the user — e.g. via email attachments.
🐴 Trojan
Pretends to be legitimate software. Allows backdoor access without the user knowing.
🕵️ Spyware
Records keystrokes and activity. Sends data (e.g. passwords) back to a hacker. Can control webcam/mic.
📢 Adware
Installs unwanted banners and popups. Doesn't cause direct damage but slows the computer.
🐛 Worm
Spreads like viruses but needs NO human action. Attaches to network tools and spreads automatically.
⭐ Exam tip: The key difference between a virus and a worm is that a worm spreads automatically without user interaction.
⚠️ Don't confuse: A Trojan is NOT a virus — it doesn't replicate. It tricks you into running it by disguising itself as safe software.

🎭 Social Engineering Attacks

Blagging (Pretexting)

Fraudsters create a fake scenario to trick victims into revealing information they wouldn't normally share. They may use personal details from social media to seem credible.

Prevention: Use biometric measures (harder to divulge); maximise privacy settings on social media.

Phishing

An email or text scam where victims are tricked into believing they're being contacted by a trusted organisation (e.g. their bank) and give away passwords or account details.

Prevention: Awareness of unsolicited contacts; never give personal info; apply email filtering.

Pharming

Users are redirected to a fraudulent website that looks identical to the real one. For example, a fake online store asking for credit card details.

Prevention: Check the URL carefully; use HTTPS for banking/e-commerce; use website filters.

Shoulder Surfing

Fraudsters physically look over your shoulder to see PINs or passwords being typed — often at ATMs or in public places.

Prevention: Be aware of surroundings; cover hands when typing a PIN; position screens away from view.

🎣 Phishing

  • Fake email/text
  • Mimics trusted org
  • Steals login details
  • Digital attack

🌾 Pharming

  • Fake website
  • Looks real
  • Steals payment info
  • Redirects traffic
⭐ Exam tip: Phishing = fake message. Pharming = fake website. Easy to mix up — remember Phishing = fishing for info in your inbox.

🔒 Methods to Prevent Cyber Threats

Biometric Measures

Fingerprints, facial recognition, and iris scans verify identity. More secure than passwords as they cannot be guessed or forgotten, but require the user to be physically present.

Automatic Software Updates

Keeps antivirus, firewalls and OS up-to-date against new malware and recently discovered vulnerabilities. Better than manual updates because users may forget or delay updating.

CAPTCHA

Tests that distinguish humans from bots using images machines can't interpret. Ensures that users are human, not automated scripts.

Password Systems

Most accounts require passwords. Secure sites use two-factor authentication (2FA) — e.g. a second password or phone confirmation for large transactions.

Email Confirmation

When registering online, a confirmation link sent by email verifies that the email account is real and belongs to a human.

Anti-Virus Software

Scans intermittently to detect malware by comparing files against a database of known virus codes. Quarantines infected files. Must be regularly updated to detect new viruses.

⭐ Exam tip: For "why are automatic updates better than manual?", give TWO reasons: (1) users may forget to update manually; (2) automatic updates happen immediately so protection is always current.

🔍 Penetration Testing

Penetration testing is legitimate testing of an organisation's computer system to identify vulnerabilities that an attacker could exploit. By finding these first, they can be patched before a real attack occurs.

⬜ White Box Testing

  • Tester is given info about the network
  • Knows: architecture, source code, IP addresses
  • Simulates a malicious insider
  • More thorough — knows where to look

⬛ Black Box Testing

  • Tester given very little information
  • Knows: almost nothing
  • Simulates an outside attack
  • Realistic — mirrors real attacker's position
The goal of penetration testing is to find vulnerabilities BEFORE attackers do — so they can be fixed.
⭐ Exam tip: White box = insider threat simulation (knows the system). Black box = external attack simulation (knows nothing). Remember: black box = blind like a black box recorder before it's found.
