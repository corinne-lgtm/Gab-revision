Variables, types and input

A variable stores a value under a name. Use = to assign a value; use input() to read text; convert it with int() or float() when you need numbers.

Assignment

score = 10
score = score + 5
print(score)

15 — the value is updated.

Types

age = 15             # integer
height = 1.78       # float
name = "Gabriel"    # string
passed = True        # Boolean

Strings are text, integers are whole numbers, floats include decimals, Booleans are True/False.

Input

age = int(input("Age? "))
print(age + 1)

input() returns a string. int() converts it to an integer.

Operators and decisions

Operators do calculations and comparisons. An if statement runs only when its condition is True. Indentation is part of Python syntax.

Arithmetic

print(7 // 2)  # 3
print(7 % 2)   # 1
print(2 ** 3)  # 8

// means integer division; % returns the remainder; ** means power.

Comparisons and logic

age = 16
if age >= 16 and age < 18:
    print("Sixteen or seventeen")
else:
    print("Other")

Remember == tests equality. = assigns a value.

Selection

mark = 72
if mark >= 80:
    print("A")
elif mark >= 60:
    print("B")
else:
    print("C")

Test the conditions in order: only the first matching branch runs.

Iteration: for and while

A for loop usually repeats a known number of times. A while loop continues while its condition is true. Avoid infinite loops.

for and range

for i in range(1, 4):
    print(i)

Output: 1, 2, 3. The end of range is excluded.

while

count = 3
while count > 0:
    print(count)
    count -= 1

Output: 3, 2, 1. Updating count prevents an infinite loop.

Accumulator

total = 0
for number in [2, 4, 6]:
    total += number
print(total)

Output: 12. This pattern is useful for totals and averages.

Strings and lists

Indexing starts at zero. You can access individual characters or list items, and loop through a list.

Indexing

word = "PYTHON"
print(word[0])
print(word[-1])

P and N. Index 0 is the first position.

Lists

marks = [5, 7, 9]
marks.append(10)
print(marks[1])
print(len(marks))

Output: 7 and 4.

String operations

name = "Gab"
print(name.upper())
print(len(name))

Output: GAB and 3.

Subprograms and scope

Use a function to reuse code and return a result. Parameters are the inputs to a function. A local variable belongs inside its function.

Functions

def double(n):
    return n * 2

print(double(5))

Output: 10. return gives the caller a value.

Procedures

def welcome(name):
    print("Hello " + name)

welcome("Gab")

A procedure performs an action; it does not need to return a result.

Local variables

def calculate():
    subtotal = 12
    return subtotal + 3

print(calculate())

Output: 15. subtotal is local to calculate().

Robust programming and testing

Validation prevents invalid inputs. Testing checks expected, boundary and erroneous cases. Clear variable names and comments make code maintainable.

Validation

age = int(input("Age? "))
if 0 <= age <= 120:
    print("Valid")
else:
    print("Invalid")

A range check prevents impossible age values.

Test types

# Test an age checker:
# Normal: 18
# Boundary: 0, 120
# Invalid: -1, 121

Good testing includes typical, boundary and erroneous inputs.

Common errors

# Syntax: missing colon after if
# Runtime: dividing by zero
# Logic: using > instead of >=

A program can run but still give the wrong result: that is a logic error.

Files and structured data

Programs can read and write text files. A record groups fields about one item; a two-dimensional list organises data into rows and columns.

Write a file

with open("scores.txt", "w") as f:
    f.write("Gab: 8\n")

Opening with w writes text and overwrites an existing file.

Read a file

with open("scores.txt", "r") as f:
    print(f.read())

Opening with r reads an existing text file.

2D lists

grid = [[1, 2], [3, 4]]
print(grid[1][0])

Output: 3 — row 1, column 0.
