Question 1 Number system conversions 8 marks
(a) Convert the denary number 185 to binary. Show your working. [2 marks]
(b) Convert the binary number 10110110 to denary. [1 mark]
(c) Convert the binary number 11010011 to hexadecimal. Show your working. [2 marks]
(d) Convert the hexadecimal value A7 to denary. Show your working. [2 marks]
(e) State one reason why hexadecimal is often used instead of binary by programmers. [1 mark]

Mark Scheme — Question 1

✓(a) 185 in binary = 10111001. Award 1 mark for correct method (repeated division or place values shown), 1 mark for correct answer.
✓(b) 10110110 = 128+32+16+4+2 = 182. [1 mark]
✓(c) 1101 = D, 0011 = 3 → D3. Award 1 mark for correctly splitting into nibbles, 1 mark for correct hex answer.
✓(d) A = 10, 7 = 7. (10 × 16) + 7 = 160 + 7 = 167. Award 1 mark for method, 1 mark for answer.
✓(e) Any one of: hexadecimal is more compact / easier to read than long binary strings; one hex digit represents 4 bits clearly; used in memory addresses and colour codes. [1 mark]
Question 2 Binary addition and overflow 6 marks
(a) Perform the following binary addition and give the result in binary. Show all carries. [2 marks]

01001110 + 00110101
(b) Check your answer by converting both original numbers to denary and adding them. [2 marks]
(c) Explain what is meant by an overflow error in binary arithmetic. Give an example. [2 marks]

Mark Scheme — Question 2

✓(a) 01001110 (78) + 00110101 (53) = 10000011 (131). Award 1 mark for correct working showing carries, 1 mark for correct 8-bit answer.
✓(b) 01001110 = 78, 00110101 = 53, 78 + 53 = 131. Matches 10000011 ✓ [1 mark method, 1 mark for correct totals matching].
✓(c) Overflow occurs when the result of a calculation is too large to be stored in the available number of bits [1 mark]. Example: in 8-bit arithmetic, 200 + 100 = 300, which exceeds the maximum value of 255, causing the result to be incorrectly truncated [1 mark].
Question 3 Two's complement 6 marks
(a) Describe the steps used to represent a negative number using two's complement. [3 marks]
(b) Using two's complement, represent −75 as an 8-bit binary number. Show all working. [3 marks]

Mark Scheme — Question 3

✓(a) Step 1: Write the positive version of the number in binary [1 mark]. Step 2: Flip all the bits (invert, one's complement) [1 mark]. Step 3: Add 1 to the result [1 mark].
✓(b) +75 = 01001011 [1 mark] → flip → 10110100 [1 mark] → add 1 → 10110101 = −75 [1 mark].
Question 4 Character encoding 6 marks
(a) The ASCII code for the letter 'M' is 77. What is the ASCII code for the letter 'm'? Explain how you know. [2 marks]
(b) Describe two differences between ASCII and Unicode. [4 marks]

Mark Scheme — Question 4

✓(a) 'm' = 109 [1 mark]. Lowercase letters always have an ASCII value 32 higher than their uppercase counterpart (77 + 32 = 109) [1 mark].
✓(b) Award 2 marks per difference (1 for the point, 1 for development):
• ASCII uses 7 bits (128 characters) whereas Unicode uses more bits (e.g. UTF-8 up to 4 bytes) and can represent 140,000+ characters [2 marks].
• ASCII only supports the Latin/English alphabet, while Unicode supports virtually every writing system and language in the world including non-Latin scripts and emoji [2 marks].
• Unicode files are typically larger because more bits are used per character, whereas ASCII files are more compact [2 marks]. (Accept any two, 2 marks each.)
Question 5 Image file sizes 7 marks
(a) State the formula used to calculate the file size of a bitmap image. [1 mark]
(b) Calculate the file size in kilobytes (KB) of a bitmap image that is 800 × 600 pixels with a colour depth of 24 bits. Show all working. [3 marks]
(c) A graphic designer reduces the colour depth of the image from 24 bits to 8 bits. Describe two effects this will have on the image. [2 marks]
(d) State what is meant by the resolution of a digital image. [1 mark]

Mark Scheme — Question 5

✓(a) File size = width × height × colour depth [1 mark].
✓(b) 800 × 600 × 24 = 11,520,000 bits [1 mark] ÷ 8 = 1,440,000 bytes [1 mark] ÷ 1024 = 1406.25 KB (accept 1,440,000 bytes or 1406 KB) [1 mark].
✓(c) The file size will decrease (8 bits vs 24 bits means a ⅓-sized file) [1 mark]; the image will have fewer colours available (256 colours vs 16.7 million), potentially looking less realistic or banded [1 mark].
✓(d) Resolution is the total number of pixels in an image, typically expressed as width × height (e.g. 800 × 600) [1 mark].

Question 7 Sound and file sizes 5 marks
(a) Explain what is meant by the sample rate when digitising sound. [2 marks]
(b) A mono audio recording has a sample rate of 22,050 Hz, a bit depth of 16 bits, and a duration of 2 minutes. Calculate the file size in MB. Show all working. [3 marks]

Mark Scheme — Question 7

✓(a) The sample rate is the number of times per second that the amplitude of the sound wave is measured and recorded [1 mark]. A higher sample rate captures more detail and produces better quality audio, but results in a larger file [1 mark].
✓(b) Duration = 2 × 60 = 120 seconds. File size = 22,050 × 16 × 120 × 1 = 42,336,000 bits [1 mark] ÷ 8 = 5,292,000 bytes [1 mark] ÷ 1,048,576 ≈ 5.05 MB (accept 5,292,000 B or 5168 KB) [1 mark].
Question 8 Compression 7 marks
(a) Describe the difference between lossy and lossless compression. [4 marks]
(b) The following data represents a row of pixels in a simple black and white image. Each letter represents a pixel colour (W = white, B = black):

Apply run-length encoding (RLE) to compress this row. Show the compressed output. [2 marks]
(c) Suggest one type of file where lossy compression would not be appropriate. Explain your answer. [1 mark]

Mark Scheme — Question 8

The original file can be perfectly reconstructed [1 mark]. (Example for each: lossy = JPEG, MP3; lossless = PNG, ZIP.)
✓(b) 6W 2B 4W 5B 4W [2 marks — award 1 mark if mostly correct with minor error].
✓(c) Text files / program source code / medical images / legal documents — any one [½ mark]. Because lossy compression could alter or corrupt the data, making text unreadable, code unable to run, or a medical image inaccurate, which could have serious consequences [½ mark].
